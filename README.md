3. Project Overview
 Sipesihle Tutoring Academy is an educational tutoring that provides academic support to high school and university students.
 This website is the academy's first official website.It was developed to introduce the academy, provide information about its tutoring service and make it easier for students to enquire about academic assitance.

The website was developed using HTML, CSS and JavaScript. It includes responsive layouts to improve the experience for vistors using desktop computers,tablets and mobile phones.

4. Website Goals and Objectives
 The main goals of the website are to:
 -Introduce Sipesihle Tutoring Academy to student and parents.
 -Establish an online presence for Sipesihle Tutoring Academy.
 -Provide information about the academy and its tutoring services.
 -Promote STEM, Accounting and Economics subjects.
 -Allow students to submit enquiries.
 -Make contact information and location details accessible.
 -Create a user-friendly and responsive website.

5. Key Features and Functionality
-Home page introducing the academy.
-About page providing information about the academy.
-Services page explaining the tutoring services.
-Enquiries page containing an enquiry form.
-Contact page with contact information, business hours and an embedded map.
-Responsive navigation menu.
-Responsive images and image gallery.
-JavaScript form validation and confirmation messages.
-CSS styling and responsive layouts.
